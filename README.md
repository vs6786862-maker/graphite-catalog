# Графитовый каталог — демо-шаблон интернет-магазина

Одностраничное демонстрационное приложение магазина с тёмной темой, хеш-роутингом
и полностью условными данными. Все товары, цены, продавцы и статистика —
сгенерированные демо-значения, которые не описывают реальные объекты.

**Живая версия:** https://graphite-catalog.surge.sh

## Возможности

- Каталог из 120 демо-товаров с поиском, фильтрами по категориям и пагинацией
- Страница товара: фотогалерея-заглушка, комплектация, отзывы, панель покупки
- Корзина на localStorage: изменение количества, итог заказа, демо-оформление
- Разделы: линеек, серий, категорий, заявок, услуг, добавления товара, входа
- Тёмная тема в 3 цвета: чёрный фон, светло-серый текст, синий акцент #006bb9
- Типографика: Golos Text (осн. текст) + Martian Mono (CAPS-подписи), вес 800
  на дисплейных элементах

## Стек

- [Next.js 16](https://nextjs.org) (App Router, Turbopack) + React 19 + TypeScript
- [Tailwind CSS 4](https://tailwindcss.com) с семантическими дизайн-токенами
- Компоненты [shadcn/ui](https://ui.shadcn.com) в `src/components/ui`
- Шрифты `@fontsource-variable` (Golos Text, Martian Mono)

## Запуск для разработки

```bash
npm install
npm run dev
```

Откроется http://localhost:3000. Роутинг хеш-овый: `/#/`, `/#/catalog`,
`/#/items`, `/#/categories`, `/#/requests`, `/#/services`, `/#/cart`,
`/#/submit`, `/#/login`, `/#/item/<id>`.

## Статическая сборка

Приложение не требует серверной части: сборка целиком выгружается в статику.

```bash
STATIC_EXPORT=1 npx next build   # результат — в каталоге .next-export/
```

Готовую папку `.next-export/` можно выложить на любой статический хостинг
(surge.sh, GitHub Pages, Netlify и т. п.). Для surge:

```bash
npx surge ./.next-export my-site.surge.sh
```

## Структура

```
src/
├── app/                    # каркас Next.js (layout, page, тема в globals.css)
├── components/site/        # каркас сайта: шапка/футер, роутер, карточки
│   └── pages/              # страницы: home, catalog, item, cart, ...
├── components/ui/          # базовые UI-компоненты (shadcn/ui)
├── lib/catalog.ts          # генератор демо-данных (товары, серии, заявки)
└── lib/cart.ts             # корзина на localStorage
```

## Примечания

- Демо-данные детерминированно генерируются в `src/lib/catalog.ts`;
  никакого бэкенда и базы данных не требуется.
- Формы входа, регистрации, отзывов и добавления товара — демонстрационные:
  данные никуда не отправляются и не сохраняются.
